# /web-info — Статус Apache и публикаций 1С

Показывает состояние Apache HTTP Server, список опубликованных баз и последние ошибки.

## Usage

```
/web-info
```

## Параметры подключения

Прочитай `.v8-project.json` из корня проекта. Если задан `webPath` — используй как `-ApachePath`.
По умолчанию `tools/apache24` от корня проекта.

## Команда

```powershell
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/web-info.ps1" <параметры>
```

### Параметры скрипта

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `-ApachePath <путь>` | нет | Корень Apache (по умолчанию `tools/apache24`) |

## Как читать вывод

Три секции: состояние сервера, список публикаций (имя, URL, строка соединения, теги сервисов),
хвост журнала Apache.

| В выводе | Что значит |
|----------|------------|
| `Status: Остановлен` | Apache не запущен — публикации в `httpd.conf` есть, но URL-ы не отвечают. Поднимается повторным `/web-publish` |
| `[WARN] Обнаружен сторонний Apache` | На машине работает чужой экземпляр — может держать порт; наши команды им не управляют |
| `[WS HTTP OData]` | Что опубликовано для базы: SOAP-сервисы, HTTP-сервисы, стандартный OData |
| `+ext` (`WS+ext`) | Публикуются и сервисы, поставляемые расширениями конфигурации |
| `(нет публикаций)` | Apache стоит, но ни одна база не опубликована — нужен `/web-publish` |
| `(пусто)` / `(нет файла)` в ошибках | Норма, а не сбой: журнал пуст или ещё не создан |

Секция ошибок — последние строки журнала Apache, в том числе информационные (`notice` при старте).
Наличие строк само по себе о проблеме не говорит — смотри уровень (`error`, `warn`).

Публикация в списке не означает, что база отвечает: `/web-info` читает `httpd.conf` и дескрипторы,
а не опрашивает URL-ы. Если нужно убедиться — дёрни URL.

## Примеры

```powershell
# Статус по умолчанию
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/web-info.ps1"

# Указать путь к Apache
powershell.exe -NoProfile -File "${CLAUDE_SKILL_DIR}/scripts/web-info.ps1" -ApachePath "C:\tools\apache24"
```
